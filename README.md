## 📖 使用方式

### 锁定电脑（恶作剧）
双击运行 `lock.bat`，会弹出管理员权限请求，确认后：
- 所有浏览器将无法上网
- 电脑看似"坏了"，朋友会一脸懵

### 解锁电脑（恢复）
双击运行 `unlock.bat`，按提示输入管理员密码，即可恢复正常。

## 📁 文件说明

| 文件 | 作用 |
|------|------|
| `lock.bat` | 锁定脚本（阻止所有浏览器联网） |
| `unlock.bat` | 解锁脚本（恢复浏览器联网） |
